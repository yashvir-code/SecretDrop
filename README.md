# Secret Drop

A secure document-sharing web application that aims to make sharing files simple and controlled through secure links.

## 🚀 Project Overview

Secret Drop is a full-stack web application built to explore secure file sharing, user authentication, and backend development.

**Project Status:** In Development 🚧

## 🛠️ Tech Stack

**Frontend**
- React.js
- Vite
- Axios

**Backend**
- Node.js
- Express.js
- MySQL
- JWT Authentication
- bcrypt

## ✨ Planned Features

- User registration and login
- Secure document uploads
- Shareable document links
- Automatic link expiration
- Optional password protection
- Download limits and link revocation
- User dashboard to manage shared documents

*Features will be updated as development progresses.*
